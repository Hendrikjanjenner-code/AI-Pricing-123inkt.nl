Bouw verder op de bestaande Nederlandstalige AI Pricing Decision Engine.

Doel:
Maak PriceShape niet noodzakelijk door eigen modules toe te voegen voor:
1. scraping
2. product matching
3. monitoring
4. price execution

De app moet concurrentiedata zelf kunnen verzamelen, matchen, beoordelen, monitoren en exporteren of uitvoeren.

Belangrijk:
Respecteer robots.txt, rate limits, websitevoorwaarden en wettelijke beperkingen.
Scrape alleen publieke productinformatie en bouw duidelijke throttling, logging en error handling in.
Geen omzeiling van anti-bot systemen.

MODULE 2 — PRODUCT MATCHING ENGINE

Maak een module:
backend/app/services/matching_engine.py

Doel:
Concurrentieproducten matchen aan onze SKU’s.

Matching mag niet alleen op titel.
Gebruik meerdere signalen.

Matching signalen:
- EAN match
- MPN match
- merk
- producttitel similarity
- categorie
- verpakkingseenheid
- aantal stuks
- inhoud/volume
- kleur/formaat
- producttype
- handmatige mapping

Match types:
- EXACT_MATCH
- STRONG_MATCH
- PROBABLE_MATCH
- FUNCTIONAL_MATCH
- NO_MATCH

Match confidence:
0.00–1.00

Voorbeeldregels:
- EAN gelijk → hoge score
- MPN gelijk + merk gelijk → hoge score
- titel vergelijkbaar maar pack size anders → lagere score
- pack size afwijkend → waarschuwing
- alleen categorie gelijk → geen directe match, mogelijk functioneel alternatief

Belangrijke functies:
- match_competitor_offer_to_sku()
- calculate_title_similarity()
- calculate_pack_size_similarity()
- calculate_brand_similarity()
- calculate_identifier_match_score()
- calculate_final_match_confidence()
- create_manual_match_override()
- explain_match()

Output:
- own_sku_id
- competitor_offer_id
- match_type
- match_confidence
- match_reason
- pack_size_warning
- manual_override

Reason codes:
- MATCH_EXACT_EAN
- MATCH_EXACT_MPN
- MATCH_STRONG_TITLE_BRAND
- MATCH_PACK_SIZE_DIFFERENCE
- MATCH_LOW_CONFIDENCE
- MATCH_MANUAL_OVERRIDE
- MATCH_REJECTED

backend/app/services/monitoring_engine.py

Bereken:
- prijsontwikkeling per concurrent
- prijsvolatiliteit
- voorraadbetrouwbaarheid CSRS
- prijsduurzaamheid CSS
- outlier detectie
- listing stabiliteit
- delivery stability
- nieuwe concurrenten
- verdwenen concurrenten

CSRS:
Competitor Stock Reliability Score

CSRS =
  0.40 * availability_rate
+ 0.25 * delivery_speed_score
+ 0.20 * stock_stability_score
+ 0.15 * listing_consistency_score

CSS:
Competitor Sustainability Score

Gebruik factoren:
- prijsafwijking ten opzichte van markt
- prijsvolatiliteit
- voorraadgedrag
- type concurrent
- leverbetrouwbaarheid

Monitoring alerts:

MODULE 4 — EXECUTION ENGINE

Maak een module:
backend/app/services/execution_engine.py

Doel:
Goedgekeurde prijsadviezen uitvoeren zonder PriceShape.

Ondersteun eerst:
- CSV export
- API-ready connectorinterface
- handmatige goedkeuring
- audit log

Execution modes:
- MANUAL_EXPORT
- API_PUSH_READY
- DRY_RUN
- BLOCKED_BY_GUARDRAIL

Prijsadvies mag nooit direct automatisch live zonder approval.

Execution flow:
1. Recommendation wordt berekend
2. Safety rules worden toegepast
3. Pricing Manager keurt goed
4. Execution job wordt aangemaakt
5. Exportbestand of API-payload wordt gegenereerd
6. Status wordt bijgewerkt
7. Audit log wordt gevuld

Safety rules:
- niet onder kostprijs
- niet onder min_price
- niet boven max_price
- max stijging per dag 5%
- max daling per dag 5%
- geen actie bij lage confidence
- geen actie bij ontbrekende data
- geen actie bij onbetrouwbare concurrentiesignalen
- altijd rollback mogelijk maken

Output CSV:
- sku_id
- old_price
- new_price
- change_pct
- min_price
- max_price
- reason_code
- confidence_score
- approved_by
- approved_at
- execution_status

API connector interface:
Maak generieke klasse:
PriceExecutionConnector

Met methodes:
- validate_payload()
- push_prices()
- rollback_prices()
- get_execution_status()

Maak dummy connector:
DemoCommerceConnector

Geen echte externe API nodig, maar structuur moet klaar zijn.

BELANGRIJKE BUSINESSREGELS

1. Een lage concurrentieprijs is geen reden om automatisch te volgen.
2. Een concurrent zonder voorraad telt niet als harde concurrentiedruk.
3. Een slechte productmatch mag nooit pricing beïnvloeden.
4. De laagste prijs is niet automatisch de referentieprijs.
5. Prijswijzigingen vereisen approval.
6. Alle beslissingen moeten uitlegbaar zijn.
7. Alle acties moeten in audit log staan.
8. Scraping moet respectvol en veilig gebeuren.
