PROJECT BLUEPRINT — AI Pricing Decision Engine

Build a production-grade Replit web app for an AI-supported Pricing Decision Engine for a multi-category e-commerce company.

The app must support:
1. AI pricing research
2. Internal price optimization
3. External market positioning
4. Competition Intelligence
5. Pricing recommendations
6. KPI dashboards
7. A/B test monitoring
8. CSV export for pricing tools such as PriceShape

Tech stack:
- Backend: Python FastAPI
- Frontend: React
- Database: PostgreSQL
- ORM: SQLAlchemy
- Data processing: pandas, numpy
- ML foundation: scikit-learn
- File upload/export: CSV
- Authentication: simple role-based login

User roles:
- Admin
- Pricing Manager
- Analyst
- Viewer

Main app concept:
This is not a generic AI chatbot.
This is a pricing operations platform.

The system should answer:
- Which SKU needs a price change?
- Why?
- Based on which internal and external signals?
- What is the expected margin impact?
- How reliable is the recommendation?
- Which competitors matter for pricing?
- Which competitors should be ignored?

2. Competition Intelligence Engine
Purpose:
Determine which competitors are relevant for pricing.

Important:
Competition is based on pricing impact, not assortment overlap.

Calculate per SKU:
- product_comparability_score
- price_sensitivity_score
- substitution_score
- competitor_relevance_score
- competitor_price_reliability_score
- basket_dependency_score
- strategic_importance_score
- pcis_score

PCIS = Pricing Competition Impact Score.

Competition classes:
- 0.00–0.20 Ignore
- 0.20–0.45 Monitor
- 0.45–0.70 Influence
- 0.70–0.85 Strong
- 0.85–1.00 Critical

Use category-specific logic:
- Ink/toner: high substitution relevance
- Paper: high price/volume sensitivity
- Writing supplies: high comparability
- Binders/ordners: lower direct competition weight
- Cleaning/canteen: repeat-purchase logic
- Furniture: low-velocity, margin-driven logic

Do not use the lowest competitor price by default.
Use weighted median competitor reference price.

Exclude competitors when:
- out of stock
- poor match confidence
- different pack size
- extreme outlier
- bad delivery
- low relevance
- margin guardrails would be broken

Reason codes:
- COMPETITOR_IGNORED_OUT_OF_STOCK
- COMPETITOR_IGNORED_BAD_MATCH
- COMPETITOR_IGNORED_OUTLIER
- COMPETITOR_IGNORED_LOW_RELEVANCE
- COMPETITOR_IGNORED_DIFFERENT_PACK_SIZE
- COMPETITOR_IGNORED_BAD_DELIVERY

4. Recommendation Engine
Purpose:
Generate daily pricing recommendations.

Output per SKU:
- current_price
- recommended_price
- recommended_change_pct
- expected_units
- expected_revenue
- expected_margin
- expected_margin_uplift
- confidence_score
- strategy_type
- reason_code
- safety_status
- approval_status

Safety rules:
- never below cost unless explicitly allowed
- never below min_price
- never above max_price
- max daily increase 5%
- max daily decrease 5%
- no recommendation for out-of-stock SKUs unless clearance
- flag low confidence
- flag insufficient data
- allow manual override

Reason codes:
- MARGIN_UPSIDE_PRICE_INCREASE
- COMPETITOR_PRICE_PRESSURE
- PRIVATE_LABEL_SUBSTITUTION_OPPORTUNITY
- STOCK_CLEARANCE_DISCOUNT
- BASKET_BUILDER_KEEP_COMPETITIVE
- REPEAT_PURCHASE_PRICE_STABILITY
- LOW_VELOCITY_MARGIN_PROTECTION
- KEEP_PRICE_LOW_CONFIDENCE
